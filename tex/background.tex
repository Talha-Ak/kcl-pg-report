\section{Conformal Prediction}

The theoretical foundation of CP~\cite{vovk2005algorithmic}
rests on the assumption of exchangeability of data \((X_i,Y_i)\).
Exchangeability requires that the data distribution of random variables
remains constant under any permutation.
This property is a generalization, and therefore weaker,
than the condition of being independent and identically distributed (i.i.d.).
Under this assumption, CP leverages the idea of conformity to assess
how well a new, unseen data point fits with previously observed data.
A nonconformity score \(s(x, y) \in \mathbb{R}\),
quantifies how `strange' a prediction is compared to previous examples.

The choice of the nonconformity measure (NCM) is critical
for the practical utility of CP~\cite{kato2023measures}.
While the validity guarantee holds for any NCM,
an informative NCM leads to smaller, more useful prediction sets.
Common NCMs often leverage the output of the underlying model.
For classification, examples include
the inverse predicted probability of the true class \((1 - \hat{\mathbb{P}}(y | x))\)
or the margin between the probability of the true class
and the highest probability of any other class.

The full CP procedure is computationally intensive,
requiring recalculation of scores (and potentially model retraining)
for every test point and every possible label.
To overcome this, split conformal prediction, also known as \gls{icp}
was developed~\cite{papadopoulos2002inductive} and is now the most popular variant.
Its main drawback is reduced data efficiency, as a portion of the data
must be held out for calibration and is not used for model training.

\gls{icp} works as follows:

\begin{enumerate}
    \item Split the available data into a training set \(\mathcal{D}_{train}\)
    and a calibration set \(\mathcal{D}_{cal}\).
    The training set is used to train the model,
    while the calibration set is used to compute the nonconformity scores.

    \item Train the underlying prediction model using only \(\mathcal{D}_{train}\).

    \item Compute the nonconformity scores \(s_i = s(X_i, Y_i)\)
    for all examples \((X_i, Y_i)\) in the calibration set \(\mathcal{D}_{cal}\)
    using the model trained in step 2.

    \item Determine the threshold \(\hat q\)
    by calculating the \(\frac{\lceil (n_{cal} + 1)(1 - \alpha) \rceil}{n_{cal}}\)
    empirical quantile of the calibration scores \(\{s_i\}_{i \in \mathcal{D}_{cal}}\),
    where \(n_{cal} = |\mathcal{D}_{cal}|\).

    \item For a new test input \(X_{test}\),
    calculate the nonconformity score \(s(X_{test}, y)\)
    for each possible label \(y\) using the fixed model.
    The prediction set is then all labels where
    the nonconformity score is less than or equal to the threshold:
    \[
        \mathcal{C}(X_{test}) = \{y \in Y : s(X_{test}, y) \leq \hat q\}.
    \]
\end{enumerate}

is constructed using \(s(x, y) = 1 - \mathbb{P}(y | x)\)
is shown in Figure~\ref{fig:cp-demo}.

\subsection{Evaluating Sets}

Evaluating the performance and utility of prediction sets generated by
\gls{cp} involves assessing several key aspects
beyond just the underlying model's predictive accuracy:

\begin{itemize}
    \item \textbf{Validity (Coverage)}:
    The primary theoretical guarantee provided by \gls{cp} is marginal coverage.
    Under the exchangeability assumption,
    for any chosen significance level \(\alpha \in (0, 1)\)
    the prediction set \(\mathcal{C}(X_{n+1})\) generated by the conformal algorithm
    is guaranteed to contain the true label \(Y_{n+1}\)
    with probability at least \(1 - \alpha\):
    \begin{equation}
        \label{eq:coverage}
        \mathbb{P} \left( Y_{n+1} \in \mathcal{C}(X_{n+1}) \right) \geq 1 - \alpha.
    \end{equation}

    This is typically evaluated empirically by
    calculating the percentage of test samples for which
    the true label falls within the predicted set.
    This empirical coverage should ideally match or exceed
    the nominal coverage level \(1 - \alpha\).

    While standard CP guarantees marginal coverage, research also
    explores achieving conditional coverage, ensuring validity across specific
    subgroups or conditional on certain features, though this is often more
    challenging~\cite{angelopoulos2022gentle}.

    \item \textbf{Efficiency (Set Size)}:
    While guaranteed coverage is essential,
    the practical usefulness of prediction sets hinges on their efficiency,
    typically measured by their size.
    Smaller sets provide more precise information and are generally preferred.
    Evaluation usually involves calculating the average set size across a test dataset.
    Some evaluations might also consider the informativeness of sets, for instance,
    by analysing the frequency of tight prediction sets compared
    to trivial sets, predicting almost all labels.

    \item \textbf{Adaptiveness}:
    Ideally, prediction sets should be adaptive,
    meaning their size reflects the uncertainty associated with a specific instance.
    The set should be smaller for instances where the model is confident
    and potentially larger for ambiguous instances where uncertainty is higher.
    Evaluating adaptiveness involves analysing the relationship
    between set size and measures of instance difficulty or model confidence.
\end{itemize}

\subsection{Multi-label adaptations}

Standard \gls{cp} is primarily designed for single-label classification tasks,
where each instance is associated with exactly one label from a finite set.
Multi-label tasks require adapting the framework to handle instances
that can belong to multiple classes simultaneously.
Several approaches have been proposed to extend \gls{cp} to multi-label settings,
exploiting the nature of the problem (such as implicit label dependencies)
while maintaining the theoretical guarantees of coverage.

One approach is to transform multi-label samples to the power set of labels,
treating each possible combination of labels as a distinct class.
This is known as the \emph{Power Set (PS)} method~\cite{papadopoulos2014cross}.
Standard \gls{cp} can then be applied to this transformed dataset,
resulting in sets of label sets.
While maintaining the theoretical guarantees of \gls{cp},
this naturally leads to a combinatorial explosion in the number of classes
(a dataset with K labels has 2\textsuperscript{K} possible label sets),
making it computationally expensive and impractical
for even moderately sized label sets.

A more efficient approach is to treat the multi-label problem as
a series of independent binary classification tasks,
where labels are predicted independently of one another.
This is known as the \emph{Binary Relevance (BR)} method~\cite{wang2015comparison}.
For a problem with K possible labels, this method divides the task
into K separate binary classification problems.
For each label, a unique conformal predictor is built
to determine if that specific label should be included in the prediction set.
To maintain a valid overall error rate of \(\alpha\),
a Bonferroni correction is typically applied,
requiring each of the K independent classifiers to meet
a stricter significance level of \(\frac{\alpha}{K}\).
The final prediction for a test instance is the union of all labels
predicted as positive by their respective conformal classifiers.
A comparative study by Wang et al.~\cite{wang2015comparison}
found that a BR-based approach
to multi-label conformal prediction offers a compelling trade-off
between performance and efficiency.
While its predictive efficiency was competitive,
the BR method was significantly more computationally efficient than more complex approaches,
particularly on datasets with many labels.
However, this method does ignore potential correlations between labels.

A third strategy, known as \emph{Instance Reproduction (IR)}~\cite{wang2014mlcp},
transforms the multi-label problem into a single-label problem
without resorting to the power set.
In this method, each instance-label pair is treated as a unique training example.
For instance, an image \(x\) with true labels \(\{A, B\}\)
would be transformed into two separate samples in a new, larger dataset:
\((x, A)\) and \((x, B)\).
Standard single-label \gls{cp} is then applied to this expanded dataset.
This avoids the exponential complexity of the Power Set method
but increases the size of the training set, which can still be computationally intensive.
Like Binary Relevance, this approach also breaks
the dependencies between labels for a given instance.

While these methods provide valid frameworks for adapting \gls{cp} to multi-label settings,
they share a fundamental limitation:
they are all designed to control the overall covarage rate.
In safety-critical domains like medical diagnostics, this assumption is untenable.
The clinical cost of different errors is highly asymmetric, as certain false negatives
(e.g., missing a severe condition) can have far more severe consequences than
certain false positives.

\subsection{CP in Medical Imaging}

While standard \gls{cp} provides foundational guarantees,
refinements have been developed to enhance its practicality for complex classification tasks.
Methods like Adaptive Prediction Sets (APS)~\cite{romano2020aps} specifically address
the limitation that raw classifier outputs often yield miscalibrated probabilities,
leading to prediction sets that don't achieve the target coverage level.
APS corrects this by using a calibration set to determine
the appropriate score threshold needed to empirically satisfy the desired coverage.

However, even with guaranteed coverage,
APS can sometimes produce overly large prediction sets,
particularly in domains like image classification
where models might assign small, noisy probabilities to many incorrect classes.
Addressing this, Regularized Adaptive Prediction Sets (RAPS)~\cite{angelopoulos2020raps}
introduced a regularization penalty for unlikely classes
(those ranked lower in the probability list).
This regularization effectively reduces the influence of noisy tail probabilities,
resulting in significantly smaller and more stable prediction sets
without sacrificing the formal coverage guarantees.

Despite these advancements in achieving reliable marginal coverage
\((\mathbb{P}(Y \in \mathcal{C}(X)))\)
and optimizing set size, methods like APS and RAPS fundamentally target
the overall error rate of \emph{miscoverage}.
They do not, by default, offer direct control over
specific, potentially more critical types of errors,
such as the rate of false negatives for high-risk conditions.
This control over specific, asymmetric risks
is precisely the challenge addressed by \gls{crc} and \gls{ltt}.

While these methods offer general advancements for \gls{cp} in image tasks,
specific adaptations tailored to the nuances of medical imaging have also emerged.
For instance, Lu et al.\@ explored the use of \gls{cp} in dermatology image classification,
focusing on achieving `fairness' in medical AI systems~\cite{lu2022fair}.
Their work adapts standard \gls{cp} methods to provide equalized coverage across skin types on a
skin lesion classification task, ensuring that the prediction sets contain the
true label with the desired probability (e.g., 90\%) regardless of the subgroup
membership.  This addresses important ethical considerations regarding
algorithmic bias but primarily focuses on equitable coverage guarantees across
groups rather than controlling specific types of prediction errors for the
overall population or for high-risk conditions.

Another application tackles the challenge of ordinal classification in medical imaging,
specifically for grading the severity of spinal stenosis from MRI scans~\cite{lu2022improving}.
They developed an adaptation of APS to generate prediction sets that are
contiguous intervals of severity levels.
This ensures that the true severity grade is captured
within the predicted range with high probability,
which is more intuitive for ordinal tasks than potentially disjoint sets from standard \gls{cp}.
However, like fair \gls{cp}, this approach focuses on ensuring
coverage of the true label (or rank) within the set.

Applications of \gls{cp} in medical imaging have primarily focused on ensuring that
the true label is contained within the prediction set with a certain frequency.
They do not directly offer mechanisms to control the rate of
specific, clinically critical errors, such as
minimizing the \gls{fnr} for detecting a severe condition.
This is the gap that \gls{crc} aims to fill,
by controlling the expected value of a user-defined, clinically relevant loss function,
moving beyond general coverage guarantees to manage specific diagnostic risks.

\section{Conformal Risk Control}

The guarantee of standard \gls{cp} can be viewed through the lens of
controlling the expectation of a loss function for miscoverage. The
framework of \gls{crc} introduced by Angelopoulos et al.~\cite{angelopoulos2023crc},
provides a powerful generalization of this principle, extending the guarantee to
control the expected value of a user-defined loss function.

CRC is able to leverage a calibration dataset to tune a parameter, \(\lambda \in [0, 1]\),
which controls the conservatism of the model's output,
thereby controlling the expected value of an associated loss function.

For CRC to provide its guarantee, the loss function must satisfy two key properties:
\begin{enumerate}
    \item It must be \emph{bounded}, meaning its value lies within a finite range \((-\infty, B]\)
    for some \(B < \infty\).

    \item It must be \emph{monotonically non-increasing} with respect to \(\lambda\).
    That is, as the prediction set \(\mathcal{C}_\lambda(x)\) becomes more conservative (larger \(\lambda\)),
    the associated loss \(\ell(\mathcal{C}_\lambda(X_i), Y_i)\) must either decrease or stay the same.
\end{enumerate}
The algorithm, typically implemented in a split-conformal setting similar to ICP,
proceeds as follows:

\begin{enumerate}
    \item Define a function \(\mathcal{C}_\lambda(x)\) that generates a prediction set
    based on some underlying model \(f\) and a sensitivity parameter \(\lambda\).
    These sets must be nested such that if \(\lambda' < \lambda\),
    then \(\mathcal{C}_{\lambda'}(x) \subseteq \mathcal{C}_{\lambda}(x)\).
    In other words, a prediction made at a lower, `stricter' level of \(\lambda\)
    must also be included at all more lenient levels.

    \item Specify a loss function \(\ell\) that quantifies the error
    between the prediction \(\mathcal{C}_\lambda(x)\) and the true outcome \(y\).
    This loss must obey the bounded and monotonicity properties mentioned previously.

    \item (As in ICP) Split the available data into a training set \(\mathcal{D}_{train}\)
    and a calibration set \(\mathcal{D}_{cal}\).
    Train the underlying prediction model \(f\) using only \(\mathcal{D}_{train}\).

    \item For each calibration data point \((X_i, Y_i) \in \mathcal{D}_{cal}\),
    compute the loss \(L_i(\lambda) = \ell(\mathcal{C}_\lambda(X_i), Y_i)\)
    for various values of \(\lambda\).

    \item Compute the average loss (empirical risk) over the calibration set for each \(\lambda\):
    \[
        \hat{R}_n(\lambda) = \frac{1}{n} \sum_{i=1}^n L_i(\lambda).
    \]

    \item Given a desired upper bound \(\alpha\) on the expected risk,
    find the smallest value of \(\lambda\) (denoted \(\hat{\lambda}\))
    that satisfies the risk control condition based on the empirical risk \(\hat{R}_n(\lambda)\)
    and the upper bound \(B\):
    \[
        \hat{\lambda} = \inf \left\{ \lambda \mid
        \frac{n}{n+1} \hat{R}_n(\lambda) + \frac{B}{n+1} \le \alpha \right\}.
    \]
    If no \(\lambda\) satisfies the condition,
    \(\hat{\lambda}\) is set to its maximum possible value \(\lambda_{max}\).
    Due to the monotonicity of \(\ell\), this \(\hat{\lambda}\)
    can typically be found efficiently using binary search.

    \item For a new test input \(X_{test}\),
    generate the final prediction set using the calibrated threshold \(\mathcal{C}_{\hat{\lambda}}(X_{test})\).
 \end{enumerate}

This procedure guarantees that the expected risk \(R \left( \hat{\lambda} \right)\) on a new,
unseen test point will not exceed the specified upper bound \(\alpha\):
\begin{equation}
    \label{eq:crc-guarantee}
    R \left( \hat{\lambda} \right) =
    \mathbb{E} \left[ \ell \left( \mathcal{C}_{\hat{\lambda}}(X_{n+1}), Y_{n+1} \right) \right] \leq \alpha.
\end{equation}
Note that CRC subsumes standard CP;
if the loss function is the miscoverage,
\(\ell(\mathcal{C}_\lambda(X_{n+1}), Y_{n+1}) = \mathbf{1}(Y_{n+1} \notin \mathcal{C}_\lambda(X_{n+1}))\),
then the expected loss is equivalent to the expected miscoverage rate as in Eq.~\ref{eq:coverage}.

\subsection{Application to Multi-label Classification}

We can now instantiate the general CRC framework for the task of multi-label classification,
specifically for controlling the expected value of the \gls{fnr}.

\begin{itemize}
    \item \textbf{Parameterised Prediction Set}:
    For a multi-label classification model \(f\)
    that outputs a probability \(f(x)_k\) for each class \(k\),
    a natural way to define the prediction set is by thresholding these probabilities for each class.
    We define the threshold as \(1 - \lambda\):
    \[
        \mathcal{C}_{\lambda}(x) = \{k \mid f(x)_k \ge 1 - \lambda \}.
    \]
    This construction ensures that as \(\lambda\) increases,
    the prediction set becomes more conservative (larger),
    as it includes more classes with lower probabilities.

    \item \textbf{Controlling for \gls{fnr}}:
    For a given sample with a set of true labels \(y\),
    the loss is the fraction of those true labels that are not included in the prediction set
    \(\mathcal{C}_\lambda(x)\):
    \[
        \ell(\mathcal{C}_\lambda(x), y) = 1 - \frac{|y \cap \mathcal{C}_\lambda(x)|} {|y|}
    \]
    Note that:
    \begin{enumerate}
        \item This loss is bounded, as it takes values in \([0, 1]\); we therefore have \(B = 1\).
        \item It is monotonically non-increasing with respect to \(\lambda\).
        As \(\lambda\) increases, the prediction set \(\mathcal{C}_\lambda(x)\) becomes larger,
        meaning the size of the intersection \(|y \cap \mathcal{C}_\lambda(x)|\)
        can only increase or stay the same.
        Consequently, the loss can only decrease or stay the same.
    \end{enumerate}
\end{itemize}

The calibrated threshold \(\hat{\lambda}\) will therefore produce prediction sets
that are guaranteed to control the expected \gls{fnr} across all samples at or below \(\alpha\)
as per Eq.~\ref{eq:crc-guarantee}.

\subsection{Limitations of CRC}

While CRC offers a robust and flexible framework for controlling expected risk,
its guarantees rely fundamentally on the assumption of a monotone loss function.
However, several critical metrics in machine learning do not satisfy this monotonicity constraint.
For example, consider the False Discovery Rate (FDR).
If a prediction set grows too large by including many incorrect predictions,
the proportion of false positives can increase,
violating the monotonicity requirement.
CRC, in its standard form, cannot provide guarantees for such risks.

Furthermore, CRC guarantees control the risk \emph{in expectation} \((\mathbb{E}[L] \le \alpha)\).
This means that over many repeated experiments,
the average loss will be below the threshold \(\alpha\).
While mathematically sound, in safety-critical applications like medical diagnosis,
practitioners often prefer guarantees that hold with \emph{high probability}
(\(\mathbb{P}(L \le \alpha) \ge 1 - \delta\)).

These limitations motivate the need for alternative risk-control frameworks.
Two notable frameworks provide high-probability guarantees:

\begin{itemize}
    \item \textbf{Risk-Controlling Prediction Sets (RCPS)}~\cite{bates2021rcps}:
    RCPS generates set-valued predictions that control the expected loss
    on future test points below a user-specified level \(\alpha\),
    but does so with high probability (\(1-\delta\)).
    Like CRC, RCPS utilizes a calibration dataset and
    requires the user-defined loss function to be monotone,
    meaning that larger, more conservative prediction sets
    must lead to smaller or equal loss.

    \item \textbf{Learn Then Test (LTT)}~\cite{angelopoulos2022ltt}:
    LTT is crucially distinct from both CRC and RCPS
    in that it can not only offer high-probability guarantees,
    but also handle potentially non-monotone risk functions.
\end{itemize}

\subsection{Theoretical Extension for Monotone Non-Decreasing Risks}

A key limitation of the standard \gls{crc} framework
is its requirement that the loss function be monotonically non-increasing
with respect to its tuning parameter, \(\lambda\).
This property is leveraged by the calibration procedure,
which selects the infimum (the smallest) \(\lambda\) that satisfies the risk control condition,
guaranteeing that all larger, more conservative \(\lambda\) values are also valid.

However, this requirement precludes the direct control of important metrics
that are naturally non-decreasing, such as prediction set size.
In these cases, a larger \(\lambda\) might correspond to a more aggressive prediction set,
which increases the associated risk.

Theoretically, the CRC framework can be adapted to control such non-decreasing loss functions
with a key modification to the parameter selection step.
Formally, where we assume \(L_i(\lambda)\) is non-decreasing in \(\lambda\), and
\[
    L_i(\lambda_{\text{min}}) \leq \alpha, \qquad \sup_{\lambda} L_i(\lambda) \leq B < \infty,
\]
then
\[
    \mathbb{E}[L_i(\hat{\lambda})] \leq \alpha,
\]
with the adaptation that instead of finding the smallest \(\lambda\) that satisfies the condition,
one would find the supremum (the largest) \(\lambda\) that meets the risk control condition:
\[
    \hat{\lambda} =
    \sup \left\{ \lambda \mid \frac{n}{n+1} * \hat{R}_n(\lambda) + \frac{B}{n+1} \leq \alpha \right\}.
\]

By selecting the largest valid \(\lambda\),
the guarantee ensures that no less conservative (smaller) \(\lambda\) value would have been chosen,
which is the correct analogue for a non-decreasing risk.
This adaptation would allow for the direct control of risks
that grow with the conservatism of the model.
While this extension is not empirically validated within the scope of this project,
it represents a promising direction for future research.

However, it is critical to note that this theoretical extension
still fundamentally relies on monotonicity.
This is a significant limitation,
as many of the most important metrics in clinical and statistical analysis are non-monotonic.
The False Discovery Rate (FDR) is a principal example.
The FDR does not have a consistent monotonic relationship with the prediction set size;
as a set grows, the addition of a correct prediction can decrease the FDR,
while the addition of an incorrect one will likely increase it.

Therefore, FDR cannot be controlled by the standard CRC procedure
or the theoretical extension described here.
To handle such complex, non-monotonic risks,
a more general and powerful framework is required.

\section{Learn then Test (LTT)}

The \gls{ltt} framework, proposed by Angelopoulos et al.~\cite{angelopoulos2022ltt},
provides a powerful alternative to CRC that directly addresses its limitations.
\gls{ltt} is designed to control risk with high probability
and is capable of handling non-monotone risk functions.
It achieves this by reframing the problem of calibrating the parameter \(\lambda\)
as a multiple hypothesis testing task.

The goal of \gls{ltt} is to find a parameter \(\hat{\lambda}\) that yields an
\((\alpha, \delta)\)-risk-controlling prediction (RCP) guarantee
where \(\alpha\) is the desired risk level and \(\delta\) is the acceptable probability
of failing to control that risk.
Formally, this means the selected prediction function
\(\mathcal{C}_{\hat{\lambda}}(x)\) must satisfy:
\[
    \mathbb{P} (R(\hat{\lambda}) \leq \alpha) \geq 1 - \delta,
\]
where the risk \(R(\hat{\lambda})\) is the expected loss over a new test point,
conditional on the calibration set \(D_{\text{cal}}\),
and the outer probability is over the random draw of the calibration set itself.
To be more precise, the guarantee can be expanded as:
\begin{equation}
    \mathbb{P}_{D_{\text{cal}}} \left( \mathbb{E}_{(X_{\text{test}}, Y_{\text{test}})}
    \left[ l(C_{\hat{\lambda}}(X_{\text{test}}), Y_{\text{test}}) \mid D_{\text{cal}} \right]
    \leq \alpha \right) \geq 1 - \delta.
\end{equation}

\gls{ltt} operates as follows:

\begin{enumerate}
    \item As with the previous methods, split the available data into
    a training set \(\mathcal{D}_{train}\) and a calibration set \(\mathcal{D}_{cal}\).

    \item Define a discrete set of candidate parameters \(\Lambda = \{ \lambda_1, ..., \lambda_N \}\)
    from which the optimal \(\hat{\lambda}\) will be selected.
    For each \(\lambda_i\), a corresponding null hypothesis \(H_i\) is defined, stating
    that the true risk \(R(\lambda_i)\) is not controlled by this threshold:
    \[
        H_i: R(\lambda_i) > \alpha.
    \]
    Rejecting the null hypothesis \(H_i\) is equivalent to accepting \(\lambda_i\)
    as a parameter that successfully controls the risk.
    Note that this risk function \(R(\lambda)\) does not need to be monotone non-increasing.

    \item Using the calibration set \(\mathcal{D}_{cal}\),
    a p-value \(p_i\) is computed for each null hypothesis \(H_i\).
    This p-value quantifies the evidence against the null.
    It is calculated by first computing the empirical risk \(R_n(\lambda_i)\)
    on the calibration data and then using a concentration inequality
    to determine the probability of observing such a low empirical risk
    if the true risk were in fact greater than \(\alpha\).
    A small p-value indicates strong evidence that the true risk is at or below \(\alpha\).

    \item Since we are testing multiple hypotheses simultaneously, a correction
    must be applied to avoid spurious rejections. LTT uses a procedure that
    controls the Family-Wise Error Rate (FWER) at a level \(\delta\).
    The simplest FWER-controlling procedure is the Bonferroni correction:
    \[
        \hat{\Lambda} = \left\{ \lambda \mid p_\lambda \leq \frac{\delta}{N} \right\}.
    \]
    More powerful methods, such as fixed sequence testing,
    can also be used to improve performance when there is a natural ordering to the hypotheses.
    Further details on these steps can be found
    in the corresponding literature~\cite{angelopoulos2022ltt, angelopoulos2022gentle}.

    \item The output of the FWER procedure is a rejection set, \(\hat{\Lambda} \subset \Lambda\),
    which contains all the \(\lambda\) values for which the null hypothesis was rejected.
    By controlling the FWER at level \(\delta\), the LTT framework guarantees that
    with probability at least \(1-\delta\), every \(\lambda\) in the set \(\hat{\Lambda}\)
    is a valid risk-controlling parameter.

    \item Any \(\lambda \in \hat{\Lambda}\) can be chosen as the final \(\hat{\lambda}\),
    and it will satisfy the \((\alpha, \delta)\)-RCP guarantee.
    In practice, one selects \(\lambda\) that is the least conservative
    (e.g., the smallest \(\lambda\)) to maximize a secondary utility metric,
    such as prediction set size.

    \item For a new test input \(X_{test}\), generate the final prediction set
    using the calibrated threshold \(\mathcal{C}_{\hat{\lambda}}(X_{test})\).
\end{enumerate}

The LTT framework thus provides a powerful alternative to CRC by addressing its primary limitations.
Firstly, by framing the calibration as a multiple hypothesis testing problem,
it can provide risk control guarantees that hold with high probability \((1-\delta)\),
a stronger and often more desirable guarantee for safety-critical applications
than the guarantee in expectation provided by CRC.

Secondly, this hypothesis-testing approach is not constrained
by the monotonicity of the risk function,
allowing it to control a wider class of critical performance metrics,
such as the False Discovery Rate (FDR), which standard CRC cannot.

\subsection{Related Work}

The Learn then Test (LTT) framework provides a general approach to risk control,
but it is useful to contrast it with other methods that also merge
conformal inference with multiple testing.
One alternative is the `Selection by Prediction' framework~\cite{jin2023selection},
which leverages conformal p-values to control the \gls{fdr}.
While both frameworks address the challenge of reliably selecting a subset of candidates,
their underlying methodologies and the nature of their guarantees differ significantly.
The primary distinction is the level at which hypotheses are tested:
LTT tests hypotheses about the \emph{overall} risk associated with a parameter choice,
whereas the Selection by Prediction approach tests hypotheses about each \emph{individual} sample.

This foundational difference dictates the mechanics of each method.
LTT evaluates the global null hypothesis that the true risk
for a given parameter \(\lambda\) exceeds a target level \(\alpha\)
(i.e., \(H_\lambda: R(\lambda) > \alpha\)).
It computes a p-value for this hypothesis using a concentration inequality
on the empirical risk of the entire calibration set.
In contrast, the conformal p-value framework generates a unique p-value for each test point,
quantifying the evidence that that specific point is `uninteresting'
(e.g., its true outcome is below a certain threshold).
This transforms the task into a classic multiple testing problem,
allowing for the application of powerful statistical procedures
that control the FDR in expectation.

Consequently, the two frameworks provide different types of statistical assurances.
By controlling the FWER of its hypothesis tests,
LTT delivers a high-probability guarantee on the chosen risk,
ensuring that \(P(Risk \leq \alpha) \geq 1 - \delta\).
This acts as a `risk ceiling', which is particularly useful in
safety-critical applications where worst-case performance is a key concern.
The Selection by Prediction method provides the standard guarantee of
expected FDR control (\(\mathbb{E}[FDP] \leq q\)).
Ultimately, LTT stands out as a more general and robust framework,
capable of controlling any risk function with a high-probability bound,
while the conformal p-value approach offers a specialized and powerful tool
specifically designed for controlling the FDR in expectation.

The methods discussed (\gls{cp}, \gls{crc}, and \gls{ltt}) represent
a nested hierarchy of techniques for providing statistical guarantees
on the outputs of black-box machine learning models.
While they share a common goal,
they offer different types of guarantees and operate under different assumptions,
as summarised in Table~\ref{tab:framework-comparison}.

Standard \glsxtrlong{cp} provides a foundational guarantee of marginal coverage.
Its primary objective is to ensure that the true label is contained
within the prediction set with a user-specified frequency.
However, it does not allow for control over other, more nuanced types of errors.

\glsxtrlong{crc} generalises this by allowing practitioners
to control the expected value of any bounded, monotone loss function.
This is a significant step forward,
as it allows for the direct control of clinically relevant metrics like the \gls{fnr}.
Its primary limitations, however, are the monotonicity requirement
and its guarantee in expectation.

\glsxtrlong{ltt} addresses these limitations by reframing the problem.
It can control any risk function (monotone or not) and provides a stronger high-probability guarantee.
This flexibility and stronger assurance make it a compelling framework for high-stakes environments,
though this may come at the cost of more conservative predictions or implementation complexity.

The theoretical distinctions highlighted form the primary motivation
for the experimental work.
While \gls{ltt} offers the most flexible and strongest guarantees on paper,
its practical performance and the trade-offs
in terms of prediction set size and statistical efficiency
compared to the simpler CRC framework are open questions
in the context of multi-label chest X-ray classification.
The following chapter will now detail the experimental design created to investigate these questions.
