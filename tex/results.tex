\section{Inductive Conformal Prediction}

The ICP framework was configured with a target error rate of \(\alpha = 0.1\),
corresponding to a nominal coverage level of 90\% for each of the 14 pathologies.

Figure~\ref{fig:baseline-coverage} presents the achieved coverage rate
for each pathology on the NIH \gls{cxr} test set,
using the DenseNet121 model.
The y-axis represents the empirical coverage rate,
calculated as the proportion of test samples for a given pathology
where the true label was correctly included in the prediction set.
The x-axis lists each of the 14 distinct pathologies evaluated.
The dashed red line indicates the nominal coverage target of 90\% \((1 - \alpha)\).

\begin{figure}
    \centering
    \includegraphics{figures/results-baseline-coverage}
    \caption{%
        Achieved class-conditional coverage rates, using DenseNet121 on the NIH dataset.
    }
    \label{fig:baseline-coverage}
\end{figure}

The results depicted clearly validate the correctness
of the class-conditional ICP implementation.
For every pathology, the empirical coverage rate meets or exceeds the 90\% target.
The variation in coverage, particularly the high rate for Hernia,
suggests that the model has differing levels of difficulty for each class,
forcing the prediction set to be more conservative for some than for others.

While ICP provides valid coverage,
its primary objective is not to control specific types of errors.
The critical question for clinical deployment is whether it is suitable
for risk-sensitive applications, where the cost of false negatives
is significantly higher than that of false positives.
To investigate this, the FNR of ICP was compared against that of CRC,
which was configured to target an FNR of \(\alpha=0.1\).
Both frameworks were evaluated under 100 different random test splits,
with the distribution of FNRs shown in Figure~\ref{fig:baseline-crc-risk}.

The result is unambiguous. The FNR for ICP is high,
centred at approximately 0.43.
In stark contrast, the FNR for CRC is tightly controlled,
with the majority of its distribution falling below the 10\% target level.
This empirically proves that CRC provides effective and reliable control of the FNR,
while standard ICP does not.
This result, while expected, is unambiguous:
standard Inductive Conformal Prediction is unsuitable for clinical or risk-sensitive applications
where controlling specific error types like the False Negative Rate is paramount.

To understand the practical implications of these different objectives,
Figure~\ref{fig:baseline-crc-size} compares the distribution of
prediction set sizes produced by each method.
A significant number of predictions are the trivial set of all 14 labels,
indicating catastrophic model uncertainty.
The CRC framework, while also favouring small sets,
almost entirely avoids producing these large, clinically uninformative sets.
This finding suggests that by focusing on a specific risk (FNR),
CRC not only achieves a safer outcome
but also does so with greater overall predictive efficiency,
as it is not forced into the same `all-or-nothing' predictions as the baseline.

To translate these findings into a tangible clinical scenario,
Figure~\ref{fig:baseline-crc-example} provides a case study
for a single test image from the NIH dataset.
The chest X-ray shown has two ground truth findings:
\emph{Atelectasis} and \emph{Infiltration}.
The corresponding prediction sets generated by both the baseline
ICP and the FNR-controlled CRC frameworks are presented.

This example illustrates the practical consequences of each framework's objective.
The baseline ICP, while aiming for 90\% per-label coverage,
produces a large set of five pathologies.
Critically, despite its size, it fails to identify \emph{Infiltration},
resulting in a clinically significant false negative.
This highlights the limitation of performing standard conformal prediction
in this class-conditional manner:
its guarantee of coverage per-class results in large, unfocused prediction sets,
presenting the clinician with a wide and less actionable range of possibilities.

In stark contrast, the CRC framework, which was explicitly configured
to control the False Negative Rate (FNR) at a 10\% target,
successfully identifies both ground truth pathologies.
By focusing on minimizing missed findings,
CRC not only achieves a safer outcome but also does so with greater precision.
The resulting prediction set is substantially smaller and more informative,
containing only one false positive alongside the two correct diagnoses.
By shifting the objective from simple coverage to the control
of a clinically relevant risk like FNR,
CRC provides outputs that are both more reliable and more useful for diagnostic support.


\section{Monotone Risk Control}

To align the CRC framework with clinical priorities,
a weighted loss function was designed (Table~\ref{tab:monotone-weights})
to selectively reduce the FNR for high-risk pathologies.
The expected outcome was a decrease in FNR for heavily weighted classes,
offset by a potential minor increase for unweighted classes.

\begin{figure}
    \centering
    \includegraphics{figures/results-weighted-crc}
    \caption{%
        Comparison of FNR for standard CRC and weighted CRC,
        using DenseNet121 on the CheXpert dataset.
    }
    \label{fig:weighted-crc}
\end{figure}

Figure~\ref{fig:weighted-crc} presents the per-pathology FNR
for both the standard and weighted CRC models.
The results directly contradict the initial hypothesis.
Contrary to expectations,
the application of weighted loss led to a systemic increase in FNR across all pathologies.
This paradoxical effect was observed regardless of a pathology's assigned weight.

The counter-intuitive result could be explained from the core mechanism of the CRC algorithm.
The weighted loss function elevates the empirical risk during calibration,
forcing the selection of a larger, more conservative global parameter \(\lambda\).
This, in turn, establishes a stricter universal probability threshold \(1 - \lambda\)
that is applied to all pathologies during inference.
Therefore, the model is globally more sceptical,
leading to smaller sets and a higher FNR for all classes.

The results of the weighted loss experiment carry important implications
for the practical application of Conformal Risk Control in high-stakes environments.
The seemingly intuitive method of using a weighted loss function
to selectively reduce risk for specific subgroups
can be ineffective and potentially counter-productive within the standard CRC framework.
It cannot be assumed that modifying the loss function will result in a simple,
localized change to the risk profile.
Changes to the loss function can have unexpected,
system-wide consequences on the final predictions by altering
the single calibration parameter \(\hat{\lambda}\) that governs all decisions.

\section{High-Probability Guarantees with LTT}

This section provides a direct, empirical comparison between CRC and LTT,
first by evaluating the reliability of their guarantees on the same monotone risk (FNR) and second,
by demonstrating LTT's unique ability to control non-monotone risks that are beyond the scope of CRC.

To conduct a direct comparison of the guarantees,
both CRC and LTT were tasked with controlling the FNR at a target level of \(\alpha = 0.1\).
For the LTT framework, the high-probability parameter was set to \(\delta = 0.1\),
meaning it is expected to control the risk with at least 90\% probability.

    \caption{%

\end{figure}

Figure~\ref{fig:results-crc-ltt-risk} presents the distribution of
the achieved FNR for both frameworks over 100 random test splits.
The distribution for CRC is centred, as expected, near the nominal 0.1 level.
However, it exhibits significant variance, with a substantial portion of the trials
resulting in an FNR that exceeds the target \(\alpha\).
This empirically demonstrates the nature of an in-expectation guarantee:
while the average performance is controlled,
there is no protection against underperformance on any given trial.
For safety-critical systems, these violations can represent unacceptable failures.

In stark contrast, the LTT framework demonstrates a fundamentally more robust behaviour.
The distribution of its achieved FNR, as shown in the same figure,
is sharply truncated at the \(\alpha\) threshold.
In over 90\% of the trials, the risk was held at or below the target level.

The practical implication of these distributions is profound.
The significant variance of CRC means that on any given day or with any given batch of patients,
the system could underperform and exhibit a clinically unacceptable False Negative Rate.
LTT's \(1 - \delta\) high-probability guarantee acts as a `risk ceiling',
providing the robust assurance that performance will not degrade beyond the specified level.

Naturally, this enhanced reliability is not without cost.
Figure~\ref{fig:crc-ltt-size} presents the corresponding distribution of prediction set sizes.
To achieve its stronger guarantee,
LTT produces prediction sets that are slightly larger on average than those from CRC.
This represents a trade-off:
a small decrease in the precision of the prediction in exchange for a significant increase
in its reliability.

Figure~\ref{fig:crc-ltt-example} provides a case study for
another single test image from the NIH dataset.
The chest X-ray shown has two ground truth findings:
\emph{Atelectasis} and \emph{Infiltration}.
The corresponding prediction sets generated by
the FNR-controlled CRC and LTT frameworks are presented.
This example illustrates the practical consequences of each framework's guarantee.
The CRC framework, while maintaining an FNR of approximately 10\% on average,
fails in this specific instance.
Its prediction set correctly identifies Atelectasis
but misses the concurrent finding of Infiltration.
This represents a clinically significant false negative,
precisely the kind of individual failure that an in-expectation guarantee permits.

In stark contrast, the LTT framework, configured to control the FNR below 10\%
with 90\% probability, successfully identifies both true pathologies.
This is a direct consequence of its high-probability `risk ceiling.'
To ensure the FNR does not exceed the threshold in most trials,
LTT must adopt a more conservative approach.
This results in a larger prediction set
(containing three false positives compared to CRC's three)
but crucially, it avoids the diagnostic error.
This single example demonstrates how LTT's more robust guarantee
translates into greater reliability for individual,
high-stakes clinical predictions.

Beyond offering a stronger guarantee on monotone risks,
the primary advantage of the LTT framework is
its ability to control arbitrary risk functions that are non-monotone;
a capability fundamentally beyond the scope of CRC.

Figure~\ref{fig:results-ltt-fdr} presents the results of applying LTT
to control FDR at various target levels, from \(\alpha = 0.05 \text{ to } \alpha = 0.5\),
over 100 random test splits.
As clearly shown, the achieved FDR on the test set
tracks consistently below the nominal target \(\alpha\).
This provides strong evidence that the LTT framework
successfully controls the FDR at the desired level,
and the fact that the achieved risk does not substantially undercut the target
indicates that the procedure is not overly conservative.
It is efficient, providing a level of risk control that is tight
to the user-specified boundary without being unnecessarily restrictive,
which would otherwise lead to overly small (and less useful) prediction sets.

This result is of practical importance, confirming that by
reframing calibration as a multiple hypothesis testing problem,
LTT successfully circumvents the monotonicity limitation inherent to CRC.
This empowers practitioners to manage a different, yet equally critical, clinical risk:
the danger of `alarm fatigue',
where a model that makes too many false positive predictions
may lead clinicians to distrust its outputs.
By allowing for the control of risks like FNR and FDR,
LTT provides a far more comprehensive proceedure
for building truly reliable and useful clinical AI systems.

\section{Robustness and Generalisation}

The previous sections have established the comparative performance of CRC,
and LTT using a DenseNet121 foundational model.
However, for these findings to be truly meaningful,
they must be robust to changes in the underlying model and the data distribution.
This section, therefore, aims to validate the generalizability of results
by systematically evaluating the frameworks across distinct datasets
(CheXpert, NIH ChestX-ray14, PadChest)
and different models (DenseNet121, ResNet50, CheXpert).
Comparing results across these heterogeneous configurations requires consideration.
The datasets and models feature different numbers of possible labels.
Therefore, to ensure a fair comparison of prediction set efficiency,
the Normalized Prediction Set Size is reported,
calculated as the average set size divided by the number of labels
applicable to that specific model-dataset pair.
Risk metrics like FNR and FDR, being ratios, are already directly comparable.

Table~\ref{tab:conformal-comparison} provides a comprehensive overview of the performance
of each conformal framework across all seven experimental configurations.

The clearest finding that can be seen is the general performance
of risk control frameworks across the configurations.
LTT consistently maintains an empirical risk below the target level
of \(\alpha = 0.1\) for both FNR and FDR, with the highest achieved risk being 0.09.
Similarly, CRC risks sit close to the target level, with slight deviations
such as ResNet on NIH.

This analysis also illuminates the inherent trade-off
between the strength of a statistical guarantee and its cost in predictive efficiency,
which is captured by the normalized set size.
A clear trend emerges when comparing CRC to LTT for FNR control.
The stronger high-probability guarantee of LTT
consistently necessitates a larger normalized set size.
On the PadChest dataset with the ResNet model, for example,
CRC achieved its goal with a normalized set size of 0.29,
whereas LTT required a size of 0.33.
This represents the cost of ensuring the risk is controlled in nearly every instance,
not just on average.

The configuration of ResNet on the CheXpert dataset provides an insight
into the behaviour of these frameworks when an underlying model is not well-suited for the task.
The results for CRC, weighted CRC, and LTT (FNR) report a risk of 0
and a normalized set size of 1.
This indicates that to satisfy the requested risk guarantee,
the only valid solution was to produce a trivial prediction set
containing every possible label for every sample.
While this result technically satisfies the statistical guarantee,
the output is clinically useless and reveals that the ResNet model, in this context for this dataset,
fails to provide a sufficiently confident signal to distinguish between pathologies.
Conformal methods will always prioritize the statistical guarantee
over the utility of the prediction,
and in doing so, they can serve as a diagnostic tool for model-task mismatch.
It is noteworthy that even in this failure,
the LTT (FDR) framework still produced an (almost) non-trivial result,
underscoring that controlling for discovery rate is a less demanding task for the model.
